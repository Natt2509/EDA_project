# EDA_project
Medical Appointment No-Show Analysis
📌 Overview
Jupyter notebook for analyzing medical appointment no-show patterns. Includes data cleaning, feature engineering, and exploratory analysis.

🏥 Dataset
Source: Kaggle - "No-show appointments"

Records: 110,526 appointments

Time Period: May 2016

Target: Predict whether patients miss appointments

🔧 Features Created
AwaitingDays - Days between scheduling and appointment

AgeGroup - Categorical age brackets

Health Conditions - Total conditions and flags

WaitingCategory - Categorized wait times

NoShow_binary - Target variable encoding

📊 Key Findings
No-show rate: 20.2%

Longer waits = Higher no-shows: 6.6% (same day) vs 32.7% (15+ days)

Same-day appointments: 39.6% of all appointments

Chronic conditions: 23.9% of patients have at least one
